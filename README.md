*A work in progress.*
This app features candidates and companies, and the match between them to help guide candidate's preparation. 
Also allows them to review companies' interview and internal culture through reviews. 
A prep tab that consists of the preparation topics/resources.

### Tech Stack
MongoDB, Express.js, React, Node.js (MERN)

### Instructions for running:
1) Clone the app. 
2) Create a .env file and configure env variables such as PORT, MONGODB_URL and JWT_SECRET
3) Cmd 'npm run dev' is sufficient to run both the backend and the frontend.
